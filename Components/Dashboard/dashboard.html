Learning

Perjalanan Belajar Kami

Materi yang kami pelajari selama praktikum Pemrograman Web di proyek Kelasik 1.0, dari struktur halaman sampai interaksi.

01

HTML

Menyusun struktur halaman dengan elemen semantik seperti header, nav, main, section, dan footer.

Progres90%
02

CSS

Styling tampilan: flexbox, grid, transition, animasi, dan pengaturan warna agar tampilan konsisten.

Progres80%
03

JavaScript

Manipulasi DOM, event listener, modal, efek typewriter, dan perpindahan konten tanpa reload halaman.

Progres70%
04

Responsive Design

Membuat layout yang nyaman di desktop maupun HP memakai media query dan grid fleksibel.

Progres75%
